# Гардероб: выкладка на Vercel

Статический сайт без сборки: `index.html` + иконки. Ничего устанавливать не нужно.

## Способ 1. Через GitHub (проще всего)
1. Создайте репозиторий на github.com (кнопка New), назовите, например, `wardrobe`.
2. В репозитории: Add file → Upload files, перетащите **всё содержимое** этой папки (index.html, vercel.json, manifest.webmanifest, папку icons), нажмите Commit.
3. На vercel.com: Add New → Project → выберите репозиторий → Deploy.
   Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми.
4. Через минуту появится адрес вида `wardrobe-xxxx.vercel.app`.

## Способ 2. Через терминал
```
npm i -g vercel
cd wardrobe-site
vercel --prod
```

## Свой домен
1. Купите домен у любого регистратора.
2. Vercel → проект → Settings → Domains → введите домен.
3. Vercel покажет **точные** DNS-записи. Обычно это:
   - для `example.com`: запись **A** на `76.76.21.21`
   - для `www.example.com`: запись **CNAME** на значение из карточки домена
   - уберите у корневого домена записи **AAAA**, они мешают
4. Подождите, пока статус станет Valid Configuration. SSL-сертификат выдастся сам.

## Важно
- На бесплатном тарифе Hobby нельзя коммерческое использование (платежи, реклама, клиентская работа). Пока это личный проект, всё в порядке. Когда начнёте зарабатывать, нужен тариф Pro.
- Вещи, добавленные в приложении внутри Claude, на новый адрес **не переедут**: хранилище браузера привязано к адресу сайта. На новом домене добавляйте их заново.
